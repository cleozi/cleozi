<h2 align="left">Hi! My name is Cleo.</h2>

###

Offensive security student focused on Active Directory exploitation, network penetration testing, and attack-chain methodology.

I document realistic attack paths, privilege escalation chains, credential abuse techniques, and post-exploitation workflows through structured lab simulations and offensive security research. My work emphasizes methodology, operational reasoning, and evidence-driven enumeration rather than simple walkthrough replication.

* Windows & Linux Privilege Escalation
* Post-Exploitation
* Infrastructure-Focused Offensive Security
* Attack Chain Analysis
